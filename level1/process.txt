# Level 1 - LZW Text Compression

This part of the project implements the LZW (Lempel-Ziv-Welch) compression and decompression algorithm for text files.

## Features

- Reads a `.txt` input file
- Compresses the text using the LZW algorithm
- Converts output codes into a binary bitstream
- Stores code length and padding information
- Writes compressed data into a `.bin` file
- Reads compressed data back from the binary file
- Decompresses the file and restores the original text
- Compares the decompressed text with the original text
- Generates CSV logs for encoding and decoding steps
- Calculates:
  - Code length
  - Compression Ratio (CR)
  - Compression Factor (CF)
  - Space Saving (SS)
  - Entropy
  - Average code length

## Files

- `LZW.py` : main implementation of text compression and decompression
- `text_file_compression_example.py` : example script for compressing a text file
- `text_file_decompression_example.py` : example script for decompressing a text file
- `sample.txt` : sample input text
- `sample_compressed.bin` : compressed binary output
- `sample_decompressed.txt` : restored text after decompression
- `sample_encode_log.csv` : encoding steps log
- `sample_decode_log.csv` : decoding steps log
