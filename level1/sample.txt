# Level 3 - LZW Compression of Difference Images

This part of the project implements LZW (Lempel-Ziv-Welch) compression and decompression for grayscale difference images.

## Overview

Instead of compressing the grayscale image directly, the program first creates a **difference image**.  
This is done to reduce redundancy and lower entropy before applying LZW compression.

The difference image is constructed as follows:

- The first pixel is kept unchanged
- In each row, starting from the second column, each pixel is replaced by the difference from its left neighbor
- In the first column, starting from the second row, each pixel is replaced by the difference from the pixel above it

Because difference values may be negative, the program shifts them into a non-negative range before applying LZW.

## Features

- Reads an image file
- Converts the image to grayscale
- Creates a difference image
- Shifts difference values into a non-negative range
- Compresses the shifted difference image using LZW
- Converts encoded output into a binary bitstream
- Stores width, height, code length, and padding information
- Saves compressed data into a `.bin` file
- Reads compressed binary data back
- Decompresses the difference image
- Reconstructs the original image from the difference image
- Saves the restored image as a `.bmp` file
- Compares the restored image with the original grayscale image
- Calculates:
  - Entropy
  - Average code length
  - Compressed file size
  - Compression Ratio (CR)

## Files

- `image_lzw_level3.py` : main implementation of Level 3
- `thumbs_up.bmp` : input image
- `thumbs_up_difference.bmp` : generated difference image
- `thumbs_up_difference_lzw_compressed.bin` : compressed binary output
- `thumbs_up_difference_restored.bmp` : restored image after decompression
